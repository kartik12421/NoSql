Q24. Compare the CRUD operations of MongoDB with equivalent SQL operations and summarize the differences.
Answer:
Operation	MongoDB	SQL
Create	insertOne()	INSERT INTO
Read	find()	SELECT
Update	updateOne()	UPDATE
Delete	deleteOne()	DELETE
MongoDB example:
db.Students.insertOne({RollNo: 105, Name: "Aman"})
db.Students.find({RollNo: 105})
db.Students.updateOne({RollNo: 105}, {$set: {Name: "Arun"}})
db.Students.deleteOne({RollNo: 105})


Equivalent SQL example:
INSERT INTO Students VALUES (105, 'Aman');
SELECT * FROM Students WHERE RollNo = 105;
UPDATE Students SET Name = 'Arun' WHERE RollNo = 105;
DELETE FROM Students WHERE RollNo = 105;


Differences:
- MongoDB stores data as BSON documents; SQL databases commonly store data in tables.
- MongoDB uses JavaScript-like query syntax; SQL uses standardized query statements.
- MongoDB supports flexible document structures; relational tables generally use predefined schemas.
